# Contributing

CHA0S AOE is a closed-source product. This repository is its public home — documentation, releases, signatures, issues — and there is no source code to contribute to.

## What is welcome

- **Bug reports** — the fastest way to make the product better. Use the bug template; include version, platform, and reproduction steps.
- **Feature requests** — framed as operational problems, not as industry trends. Use the feature template.
- **Security reports** — always, and always encrypted: [SECURITY.md](SECURITY.md).
- **War stories** — how you use the environment in real operations (no client names, no illegal specifics). Good ones end up in the docs.

## What is not accepted

- Pull requests — closed with a pointer to the [PR template](.github/PULL_REQUEST_TEMPLATE.md).
- Telemetry proposals, cloud features, account systems — the product is local-first and stays that way.
- "Add a language server / debugger / extension marketplace" — read [docs/PRODUCT.md](docs/PRODUCT.md) §7 first; these are deliberate non-goals.

## The pair

There are exactly two names in this product: **operator** and **agent**. Issues written in those terms get answered faster.
