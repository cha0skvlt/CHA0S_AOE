# Roadmap

What's ahead for CHA0S AOE. Not promises — direction. Items move as the product moves; the [changelog](CHANGELOG.md) is the record of what actually landed.

## Near

- **Release binaries**: macOS `.dmg` (universal) in GitHub Releases, GPG-signed, served from [piniq.ai/files](https://piniq.ai/files) and the demo bot.
- **Linux acceptance**: bring the Linux build to operator-accepted parity with macOS and ship it — the first post-release platform priority. Red team, OSINT, and local-model work live on Linux.
- **Payments**: buy a 1-year license ($149, 365 days) with crypto — through [@piniqai_bot](https://t.me/piniqai_bot).
- **Demo content**: short operation videos — agent drives the browser over onion, SSHes to a server, writes the report — for the README and the site.

## Mid

- **Red team KB add-on**: the knowledge corpus (chains, CVE cards, methods, playbooks) as a separate paid add-on with hybrid retrieval.
- **Agent skills ecosystem**: more built-in playbooks; skill authoring docs.
- **Phylactery tooling**: backup/export/import for agent memory — sovereign persistence across machines.

## Long

- **Team licenses**: multi-seat pricing for crews.
- **Custom builds**: tailored configurations for specific operations.
- **Agent marketplace**: shareable profiles, skills, and Phylactery schemas.
- **Windows**: frozen. Windows-based operators run their tooling in Linux VMs (Kali/WSL2) — the Linux build covers that contour. Revisit only on sustained demand from the issue tracker.

---

*The rifle and the ammo are separate. The knowledge store is dated consumable, not part of the lock; the license is annual and does not auto-renew.*
